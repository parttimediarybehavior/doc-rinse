# Release sample provenance

Only `00-synthetic-everything.docx` and its JSON label file ship in the release. The document is generated by `test.js --emit`, using original XML, ZIP construction, synthetic text and generated image bytes. It has no external input documents. License: MIT, copyright 2026 mothwake, as in the project LICENSE.

The release copy was regenerated from the current test.js rather than relying on the older binary's label. SHA-256: `ba027cb14df82049b30de646752a24cbf7ee6d95e495c3b5e5f9a10970821927`.

The build has an explicit one-file allowlist. The release test checks the embedded file list and its bytes against the source fixture. Other documents in this development directory are excluded from both the HTML and the curated release tree. A filename or label saying synthetic is not sufficient provenance.
